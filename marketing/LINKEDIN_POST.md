# Post para LinkedIn

---

🎬 Apresentando o **NoirFrame** — o sistema operacional para fotógrafos profissionais.

Nos últimos meses, construí uma plataforma SaaS completa para resolver um problema que vi de perto: fotógrafos talentosos perdendo tempo com planilhas, mensagens e processos manuais.

O **NoirFrame** reúne em um só lugar:

📅 Agenda inteligente
👤 CRM de clientes
📸 Galerias privadas com seleção de favoritas
📄 Propostas e contratos digitais
💰 Controle financeiro
✨ Assistente com IA que entende linguagem natural
🛡️ Segurança e LGPD
📊 Analytics com insights automáticos
⚡ Automações (lembretes, cobranças, follow-ups)

O diferencial? O fotógrafo escreve:
*"Ana marcou dia 28 às 18h, evento corporativo, R$ 750"*

E o sistema cria automaticamente: cliente, agenda, tarefa, cobrança e lembrete.

**Stack técnica:**
• Next.js + TypeScript + Tailwind CSS
• PostgreSQL + Drizzle ORM
• JWT Auth + bcrypt
• NLP parser para linguagem natural
• Framer Motion para animações premium
• Design system all-black cinematográfico
• 47 rotas, 20 tabelas, 8 API endpoints

O visual foi pensado para que fotógrafos de alto nível se orgulhem de mostrar para seus clientes.
