# NoirFrame — Roadmap

## ✅ MVP (Atual)
- Landing page de alta conversão
- Autenticação real (JWT + bcrypt + PostgreSQL)
- Dashboard do fotógrafo com métricas
- CRM de clientes completo
- Agenda com visualização mensal
- Ensaios com checklist e briefing
- Galerias privadas com senha e seleção
- Biblioteca de fotos
- Blog CMS
- Editor de portfólio
- Propostas comerciais com pacotes
- Contratos com assinatura digital
- Financeiro (cobranças, parcelas, dashboard)
- Kanban de tarefas
- Inbox de mensagens com respostas
- Assistente Noir com NLP
- Analytics com insights IA
- Central de segurança com score
- Automações configuráveis
- Integrações mockadas
- Command Palette (⌘K)
- Área do cliente
- Painel admin SaaS
- PWA com manifest e ícones
