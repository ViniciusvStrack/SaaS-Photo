# NoirFrame — Product One-Pager

## O que é
Plataforma SaaS premium para fotógrafos profissionais gerenciarem toda sua operação: do primeiro contato à entrega final.

## Para quem
Fotógrafos de casamento, retrato, moda, corporativo, newborn, eventos e estúdios fotográficos.

## Problema
Fotógrafos perdem horas por semana com planilhas, mensagens espalhadas, contratos manuais e entregas desorganizadas. Leads se perdem, cobranças atrasam e a experiência do cliente é inconsistente.

## Solução
Uma central única com agenda, CRM, galerias, propostas, contratos, financeiro, blog, portfólio e assistente inteligente — com estética premium que impressiona clientes.

## Funcionalidades Principais

| Recurso | Descrição |
|---------|-----------|
| Assistente IA | Interpreta texto livre e cria registros automaticamente |
| Agenda | Visualização mensal/semanal com conflitos e prazos |
| CRM | Leads, negociações, histórico e valor por cliente |
| Galerias | Links privados com senha, seleção e download controlado |
| Propostas | Pacotes, valores, aceite online pelo cliente |
| Contratos | Modelos, assinatura digital, LGPD |
| Financeiro | Cobranças, parcelas, dashboard, inadimplência |
| Blog | CMS com SEO e categorias |
| Portfólio | Editor visual com seções e layouts |
| Segurança | Score, checklist, incidentes, LGPD |
| Automações | Lembretes, cobranças e follow-ups automáticos |
| Analytics | Insights inteligentes sobre receita e performance |
| Área do Cliente | Portal premium para galeria, proposta e contrato |
